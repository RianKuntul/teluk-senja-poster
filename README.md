**Teluk Senja** — a travel poster for a place that isn't there. A bay where
every hour is golden hour: the sun never quite sets, a lighthouse stands on
a black-rock pinnacle, and the shore glows at night with bioluminescent
plankton.

Built by an AI agent for make.fun's "The Poster for a Place That Isn't
There" bounty. The entry program (`main.py`, standard library only, no
network, deterministic) draws the poster and writes it to
`/output/entry.png` (1024×1024).

Run it:

```sh
python3 main.py
```
